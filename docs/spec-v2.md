# Fathom v2 仕様（2026-10-23 壁打ちで決定）

## コンセプト
**世界の果ての「いま」に、みんなで潜る集中タイマー**

- メイン：PC で作業・勉強する人のための「定時潜航」
- サブ：瞑想・睡眠などは「ソロ潜航」として自分のペースで使える
- ゴール：まずユーザーを集める。その過程で 1 円でも収益が出たら勝ち
- 合格ライン：作り手自身が毎日使いたくなること

## 定時潜航
- 全員共通の時計で動く（サーバーでの同期は不要）
  - :00〜:25 潜航 → :25〜:30 浮上（休憩）
  - :30〜:55 潜航 → :55〜:00 浮上（休憩）
- 潜る海は 1 時間ごとに全員共通でローテーション（例：14 時はトリスタン・ダ・クーニャ）
- 待合室：「次の潜航まで 03:12 ／ 待機中 5 人」、裏で海の音がうっすら鳴る
- :00 / :30 に全員の結晶が一斉に沈み始める（音の合図あり）
- 途中参加 OK（「残り 14:20 から合流」）
- 潜航中：一緒に潜っている人を深海の光の粒で表現。長押しの共鳴は控えめに届く
- 浮上：「今回 8 人と潜りました」、記録、シェアカード、投げ銭

## 天気で鳴る音
- 風 → うねり・突風（強いほど荒く、帯域も上がる）
- 雨 → 粒の音（量に比例）、強い雨はサーッという音も
- 気温 → 音の色（寒いほど高く澄んだ響き、暖かいほど低く柔らかい響き）
- 雲 → こもり具合（快晴は開けて明るく、曇天はこもる）
- 深く潜るほど海面の天気は遠く、こもっていく

## 人数の見せ方
- サクラは使わない。少なくても正直に出す
- 1 人のときは「今は貸し切りの海」と言い換える
- 「今週 23 人が潜りました」「前回の潜航：3 人」など、期間でまとめた数字も出す

## 収益
- 浮上画面に控えめな投げ銭（例：「この海の灯りを保つ ¥100」）
- Stripe の Payment Link を使う（URL は環境変数で差し込む）
- 特定商取引法に基づく表記ページが必要
- 機能制限型の課金はユーザーが集まってから

## MVP（2〜3 週間）
1. 天気で鳴る音
2. 定時潜航（時間割・毎時の海・待合室・途中参加）
3. 浮上画面（一緒に潜った人数・記録・シェアカード・投げ銭リンク）
4. 低負荷モード（タブが裏に回ったら 3D 描画を止める）

## 後回し
- 潜航ログ・スタンプ帳
- 「まもなく潜航」の通知
- ソロ潜航の作り直し（瞑想・睡眠）
- Sleep モード、SYNC（3 語座標）、手紙機能、英語中心の HUD は縮小または削除を検討
